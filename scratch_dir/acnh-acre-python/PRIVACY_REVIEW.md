# Privacy Review

This scratch directory was curated from an old local ACNH experiment before
being prepared for git.

Removed before staging:

- Local absolute paths and usernames.
- Real ACNH save data.
- Personal island/save fragments.
- Generated acre/item dump binaries.
- Spreadsheet-derived bulk data.
- Python bytecode caches.

Before pushing, re-run local scans for absolute paths, credentials, personal
names, save export filenames, generated acre/item dumps, spreadsheets, and
Python caches.
